# User Guide

## Opening the App

Open the Wedding Registry Mini App from Telegram. The app verifies your Telegram account automatically.

## Access

If you see a no-access screen, ask a Super Admin to grant you a role.

## Dashboard

The dashboard shows:

- Total events
- Total gifts
- Contributors
- Cash totals separated by currency
- Gift type distributions
- Trends and charts

## Events

Use Events to browse active weddings.

You can search and filter events. Open an event to see details and gifts.

## Gifts

Gift records show giver, gift type, amount or weight, date, and notes when available.

Cash values always show the original currency.

## Search

Use Search to find events or gifts across the registry.

Use Command Palette with:

- `Ctrl+K` on Windows/Linux
- `Cmd+K` on macOS

## Theme and Language

The app supports:

- Light mode
- Dark mode
- Telegram theme
- Uzbek
- Russian
- English

## Admin Features

Admin features are visible only to Super Admins.

## Data Safety

Records deleted in the app are hidden, not permanently erased. Super Admins can restore them.
