# Release Notes

## Version 0.1.0

Initial production candidate for Wedding Registry Telegram Mini App.

### Highlights

- Telegram identity verification.
- Event and gift ledger.
- Super Admin and Viewer roles.
- Server-side dashboard analytics.
- Admin control panel.
- Immutable audit history.
- Version restore for events and gifts.
- Report exports.
- Private storage buckets.
- Uzbek, Russian, and English support.
- Production security headers and dependency audit.
- Full database integration test suite.

### Known Pre-Launch Gates

These must be completed in staging before public launch:

- Telegram iOS test.
- Telegram Android test.
- Telegram Desktop test.
- Telegram Web test.
- Lighthouse audit.
- Screen-reader audit.
- Load test with production-like data.
- Supabase backup restore drill.
- Production monitoring and alerting setup.

### Upgrade Notes

There is no previous public version.
